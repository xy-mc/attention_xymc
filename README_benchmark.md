# 注意力机制性能测试

这个项目实现了多种注意力机制的CUDA实现，并提供了性能对比测试。

## 实现的方法

### 1. Naive Attention
- **文件**: `src/kernels/naive_attention.cu`
- **特点**: 标准的注意力机制实现
- **公式**: `Attention(Q,K,V) = softmax(QK^T/√d_k)V`
- **适用场景**: 通用注意力，支持自注意力和交叉注意力

### 2. Flash Attention
- **文件**: `src/kernels/flash_attention.cu`
- **特点**: 流式注意力实现，使用在线softmax
- **优势**: 内存效率更高，适合长序列
- **适用场景**: 长序列注意力计算

## 编译和运行

### 编译
```bash
mkdir build
cd build
cmake ..
make -j4
```

### 运行性能测试
```bash
./bench_attention
```

## 测试维度

测试程序会测试以下维度组合：

| 批次大小 | 头数 | 查询长度 | 键/值长度 | 头维度 | 描述 |
|---------|------|----------|-----------|--------|------|
| 1 | 8 | 128 | 128 | 64 | 小规模 |
| 1 | 8 | 512 | 512 | 64 | 中等规模 |
| 1 | 8 | 1024 | 1024 | 64 | 大规模 |
| 1 | 8 | 2048 | 2048 | 64 | 超大规模 |
| 2 | 8 | 1024 | 1024 | 64 | 多批次 |
| 1 | 16 | 1024 | 1024 | 64 | 多头 |

## 性能指标

### 1. 执行时间 (ms)
- 平均执行时间，包括GPU计算和同步时间

### 2. GFLOPS
- 每秒十亿次浮点运算
- 计算公式: `FLOPs / 执行时间`
- FLOPs = B×H×M×N×D + B×H×M×N×2 + B×H×M×N×D

### 3. 内存带宽 (GB/s)
- 内存访问带宽
- 计算公式: `内存访问量 / 执行时间`
- 内存访问量 = (Q + K + V + O) 的数据量

## 误差分析

### 1. 最大误差
- 与参考实现的最大绝对误差

### 2. 平均误差
- 与参考实现的平均绝对误差

### 3. 相对误差
- 相对于参考实现的相对误差

## 输出文件

测试程序会生成以下文件：
- `attention_result_BxHxMxNxD.txt`: 每个测试维度的计算结果

## 自定义测试

要添加新的测试维度，修改 `apps/bench_attention.cu` 中的 `test_cases` 向量：

```cpp
std::vector<attention::AttentionDims> test_cases = {
    {batch_size, num_heads, seq_len_q, seq_len_kv, head_dim},
    // 添加更多测试用例...
};
```

## 注意事项

1. **内存要求**: 大规模测试需要足够的GPU内存
2. **精度**: 不同实现可能有数值精度差异
3. **预热**: 测试包含预热步骤以获得准确的性能数据
4. **同步**: 所有测试都包含CUDA同步以确保准确性
